Privacy policy

Last updated 5 October 2026

Kosmos is a personal tool operated by the owner of the UnCut Wisdom YouTube channel ("we"). It has a single user, the operator, and does not collect information about the public or about viewers.

YouTube API Services

Kosmos uses YouTube API Services. By using Kosmos you are agreeing to be bound by the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

What Kosmos accesses

With the operator's permission (Google OAuth), Kosmos requests two YouTube scopes:

  • youtube.upload: to upload videos to the operator's own channel.
  • youtube.readonly: to read the operator's channel name, subscriber count, view count, and the view, like and comment counts and privacy status of videos Kosmos uploaded.

Kosmos does not read comments' text, private messages, viewer identities, or any other channel's private data.

How the data is used and stored

  • The data is used only to upload the operator's videos and to produce the operator's daily performance report.
  • The OAuth token, upload records and statistics are stored only on the operator's own computer. Kosmos has no server and no database in the cloud.
  • Statistics are refreshed daily from YouTube.
  • Data is never sold, used for advertising, or shared with anyone, with one exception below.

AI processing

To speak the daily report, Kosmos sends the operator's own channel statistics (counts and video titles) to Anthropic's Claude model, under the operator's own Anthropic account. Anthropic's handling is described in the Anthropic privacy policy. No other Google user data is sent to third parties.

Revoking access and deleting data

Access can be revoked at any time on the Google security settings page. Deleting Kosmos's local data folder removes all stored data. Requests about this policy: kosmosxkaos@gmail.com.

Changes

If this policy changes, the date at the top will be updated.
